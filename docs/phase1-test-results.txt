## Functional Verification (Manual Testing)

All Phase 1 nesting restrictions work correctly when tested manually:

### Same-delimiter Prevention (Working ✓)
Input:  *bold *nested* bold*
Output: (bold (plain_text "bold *nested")) (plain_text " bold*")
Result: Inner *nested* NOT parsed as bold (correct)

### Cross-delimiter Nesting (Working ✓)
Input:  *bold /italic/ bold*
Output: (bold (plain_text) (italic (plain_text)) (plain_text))
Result: Italic DOES nest inside bold (correct)

### Code/Verbatim Markup Prevention (Working ✓)
Input:  This is ~code with *bold* text~ here
Output: (plain_text) (code) (plain_text)
Result: No bold node inside code (correct)

### Link Nesting Prevention (Working ✓)
Input:  [[path-to-file][See reference to other-file here]]
Output: (regular_link (plain_text))
Result: Description is plain_text, not another link (correct)

### Markup in Link Descriptions (Working ✓)
Input:  [[/path/to/file][description with *bold* text]]
Output: (regular_link (plain_text) (bold (plain_text)) (plain_text))
Result: Bold IS allowed in description (correct)
