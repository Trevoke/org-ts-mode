# Phase 2.1 Complete: Stateful Nesting Removed

**Date**: 2025-11-14
**Duration**: 4 days (Nov 11-14)
**Status**: ✅ COMPLETE

## Summary

Successfully removed stateful nesting logic from the external scanner. The scanner no longer maintains a delimiter stack and has been reduced from 20 bytes to 8 bytes (6 bytes data + 2 bytes padding). All stack-based functions have been removed, and `scan_emphasis` has been simplified by 50%.

## Changes Made

### 1. Scanner State Structure Reduced

**Before (20 bytes)**:
```c
typedef struct {
    char delimiter_stack[MAX_EMPHASIS_DEPTH];  // 16 bytes
    uint8_t stack_depth;                        // 1 byte
    uint8_t state_flags;                        // 1 byte
    uint8_t padding[2];                         // 2 bytes
} Scanner;  // 20 bytes total
```

**After (8 bytes)**:
```c
typedef struct {
    int32_t last_char;      // 4 bytes - Last character seen (for PRE boundary)
    bool at_line_start;     // 1 byte - Are we at beginning of line?
    uint8_t state_flags;    // 1 byte - Bit flags for future extensions
                           // 2 bytes - padding (compiler-added)
} Scanner;  // 8 bytes total (6 data + 2 padding)
```

**State Reduction**: 60% smaller (20 → 8 bytes)

### 2. Functions Removed

All stack-based nesting control functions have been removed:

- **`is_delimiter_on_stack()`** (~12 lines) - Checked if delimiter was in stack
- **`push_delimiter()`** (~8 lines) - Added delimiter to stack on OPEN
- **`pop_delimiter()`** (~25 lines) - Removed delimiter from stack on CLOSE
- **Total removed**: ~45 lines of stack management code

### 3. scan_emphasis Simplified

**Before**: ~193 lines with complex stack checking logic
**After**: ~97 lines focused on boundary validation
**Reduction**: 50% smaller (96 lines removed)

Key simplifications:
- Removed all stack checking logic
- Removed OPEN vs CLOSE determination based on stack state
- Now validates PRE/POST boundaries only
- Responds to `valid_symbols` array from grammar
- Temporarily prefers OPEN when both OPEN and CLOSE are valid

### 4. Serialization Updated

**Before (20 bytes serialized)**:
- Version: 1 byte
- Stack depth: 1 byte
- State flags: 1 byte
- Padding: 1 byte
- Delimiter stack: 16 bytes

**After (6 bytes serialized)**:
- last_char: 4 bytes (int32_t)
- at_line_start: 1 byte (bool)
- state_flags: 1 byte (uint8_t)

**Serialization overhead reduced**: 70% smaller

### 5. Scanner Lifecycle Functions Updated

- **`scanner_create`**: Initializes new stateless structure
- **`scanner_serialize`**: Serializes 6 bytes instead of 20
- **`scanner_deserialize`**: Deserializes 6 bytes instead of 20
- **`scanner_destroy`**: Unchanged (simple free)

## Behavioral Changes

### Same-Delimiter Nesting

**Before Phase 2.1**: Scanner prevented same-delimiter nesting via stack
```
Input: *bold *nested* bold*
Scanner: Prevents inner * from being OPEN (checks stack)
Result: Only outer bold parsed
```

**After Phase 2.1**: Scanner allows same-delimiter nesting
```
Input: *bold *nested* bold*
Scanner: Allows inner * to be OPEN (no stack check)
Result: Nested bold currently parsed (grammar will prevent in Phase 2.2-2.3)
```

### Cross-Delimiter Nesting

**Before and After**: Always allowed (no change)
```
Input: *bold /italic/ bold*
Result: Cross-delimiter nesting works correctly
```

### Boundary Validation

**No changes**: PRE/POST boundary validation still enforced correctly:
- PRE: whitespace | - | ( | { | ' | " | BOL
- POST: whitespace | - | . | , | ; | : | ! | ? | ' | ) | } | [ | " | \ | EOL
- CONTENTS: No leading/trailing whitespace

3. This is expected and intentional

These failures will be resolved when:

- Phase 2.3: Grammar controls nesting via `valid_symbols`

### Temporary Behavior

The scanner currently "prefers OPEN when both valid":
```c
if (can_open) {
    lexer->result_symbol = open_token;
    return true;
}
```

This is a temporary simplification. Phase 2.2 will add lookahead to properly determine OPEN vs CLOSE based on whether a matching closer exists.

## Architecture Changes

### Control Flow: Before vs After

**Before (Stateful)**:
```
scan_emphasis()
├── Check PRE boundary
├── Check if delimiter on stack ← REMOVED
│   ├── If on stack: force CLOSE
│   └── If not on stack: force OPEN
├── Consume delimiter
├── Check POST boundary
└── Emit token + update stack
```

**After (Stateless)**:
```
scan_emphasis()
├── Check PRE boundary
├── Check valid_symbols (grammar control)
│   ├── can_open = valid_symbols[OPEN]
│   └── can_close = valid_symbols[CLOSE]
├── Consume delimiter
├── Check POST boundary
└── Emit token (prefer OPEN for now)
```

### Decision Making

| Aspect | Before (Stateful) | After (Stateless) |
|--------|------------------|-------------------|
| Nesting control | Scanner (via stack) | Grammar (via valid_symbols) |
| OPEN vs CLOSE | Based on stack state | Based on valid_symbols (Phase 2.2: lookahead) |
| State size | 20 bytes | 8 bytes |
| Serialization | 20 bytes | 6 bytes |
| Grammar role | Structural only | Controls nesting |
| Scanner role | Boundary + nesting | Boundary only (Phase 2.2: + lookahead) |
